# Guardian Interfaz

Proyecto de personalización y persistencia de interfaz de usuario mediante DOM y Cookies en JavaScript.  
Desarrollado para el ciclo de **1º de DAW (Desarrollo de Aplicaciones Web)**.

---

## Estructura del Proyecto

* **`index.html`**: Estructura principal con el contenedor de bienvenida y el formulario de configuración.
* **`script.js`**: Lógica de interacción con el DOM, gestión de cookies (7 días y sesión) y eventos en tiempo real (`input`, `change`, `submit`).
* **`style.css`**: Estilos del formulario y clases de tema (`.tema-claro` y `.tema-oscuro`).
* **`docs/`**: Carpeta de documentación técnica del proyecto:
  * [`docs/DOCUMENTACION.md`](docs/DOCUMENTACION.md): Documento técnico detallado con criterios, funciones y decisiones de diseño.
* **`.github/workflows/deploy-pages.yml`**: Flujo de trabajo de GitHub Actions para el despliegue automático de la aplicación en GitHub Pages.
